# SYNEXIS — Lunar Landing Site Navigator

أداة قرار لمهام القطب الجنوبي للقمر: تقارن مواقع الهبوط والتواريخ، وتحسب موقع الشمس والأرض بالنسبة للأفق والتضاريس، وتقدّر الطاقة والاتصال ومتطلبات المهمة.

## الحالة الحالية

- التحدي: NASA Space Apps 2026 — Lunar Landing Site Navigator.
- الموقع عام بالكامل: لا حسابات، ولا تسجيل دخول، ولا قاعدة بيانات.
- كل الحسابات العلمية تُنفَّذ من بيانات NASA/JPL Horizons وNASA/LRO/LOLA، دون أرقام بديلة عند فشل المصدر.
- المشروع لا يعتمد على Lovable أو Supabase أو Drizzle أو أي بوابة ذكاء اصطناعي إجبارية.
- الذكاء الاصطناعي اختياري بالكامل ويعمل حصريًا عبر NVIDIA Build API؛ بدونه تعمل «سيلين» كملخص حتمي محلي.
- واجهة الموقع بالعربية بالكامل (RTL) مع خط IBM Plex Sans Arabic المستضاف محليًا.

## التشغيل

يتطلب Bun 1.4 أو أحدث.

```bash
bun install
bun run dev        # تطوير محلي
bun run test       # اختبارات الوحدة
bun run lint       # ESLint
bun run build      # بناء إنتاج Nitro / Cloudflare
bun run preview    # بناء ثم معاينة الإنتاج (يتطلب Node.js 20+)
```

## الذكاء الاصطناعي اختياريًا عبر NVIDIA

الموقع يعمل بالكامل بدون أي مفتاح. لاستدعاء نموذج خارجي («سيلين الذكية») ينفذ:

1. احصل على مفتاح مجاني من [build.nvidia.com](https://build.nvidia.com/settings/api-keys).
2. ضعه في `.env` وفي `.dev.vars` (الملفان محليان ولا يُرفعان) مع اسم الموديل:
   ```
   NVIDIA_API_KEY=nvapi-...
   NVIDIA_MODEL=nvidia/nemotron-3.5-bolt-e4b
   ```
   - `bun run preview` ينسخ `.dev.vars` تلقائيًا إلى `.output/server/.dev.vars` قبل التشغيل.
   - `.env` يخص `bun run dev` (يقرأه Nitro كـ dotenv).
3. للإنتاج على Cloudflare: `npx wrangler secret put NVIDIA_API_KEY` بدل رفعه في أي ملف.

عند وجود المفتاح يظهر **تحليل عربي تلقائي مدمج** داخل نتيجة التقييم («سيلين تقرأ النتيجة») بعد اكتمال أفق التضاريس، إضافة إلى صندوق سؤال يدوي. عند غياب المفتاح يبقى الملخص المحلي الحتمي فقط. الموديل الافتراضي هو نيموترون Bolt e4b من NVIDIA — سريّع ودقيق ومتحقق منه بمفتاحك على حسابك؛ يمكن تغييره بتعديل `NVIDIA_MODEL`. التكامل قراءة فقط — يرسل فقط نص سؤالك واسم الموقع وتاريخه والساعات المحسوبة (بدون أي إحداثيات) — ويمر عبر دالة خادم مع حد 20 تحليلًا مدمجًا و10 أسئلة يدوية/يوم لكل IP و200/يوم للنظام وكاش 24 ساعة و8 استدعاءات/دقيقة (نحو 4 أسئلة كاملة) و350 رمزًا كحد أقصى للرد.

> **ملاحظة المعاينة:** يشغّل `bun run preview` خادم Wrangler عبر Node.js صراحةً. لا يمكن تشغيل Wrangler تحت Bun حاليًا لأن `fetch()` في Bun يتجاهل موزّع undici الذي يعتمد عليه Miniflare (مشكلة upstream). التطوير والاختبار والبناء تعمل عبر Bun، أما معاينة Cloudflare فتحتاج Node.js 20 أو أحدث.

## المكدس

- TanStack Start + TanStack Router + React 19.
- Vite 8 + Tailwind CSS 4 + مكونات shadcn/ui.
- Three.js + react-three-fiber + drei للمجسم القمري.
- Nitro بإعداد `cloudflare-module` للإنتاج.
- Vitest لاختبارات الوحدة.

## البيانات

- **JPL Horizons**: اتجاهات ومسافات الشمس والأرض، عبر دالة خادم واحدة بمدخلات محدودة، كاش 10 دقائق، وحد 30 طلبًا/دقيقة لكل IP.
- **LOLA DEM**: بلاطتا تضاريس محليتان بدقة 40 م (`public/assets/lola-south-40m.bin` و`lola-malapert-40m.bin`) مع تحقق SHA-256 قبل الاستخدام. لا تُحمَّل البلاطة إلا إذا كانت تغطي النقطة المطلوبة.
- **LROC WAC**: نسيج كرة القمر من `public/assets/lroc-moon.jpg`.
- **الأصول والخطوط**: مستضافة محليًا في `public/`؛ لا تُرسل طلبات إلى Google Fonts أو إلى نطاقات Lovable.
