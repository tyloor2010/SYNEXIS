# صفحة قياس الأبعاد (Measure)

## الهدف
أداة قياس جغرافية قمرية سريعة، تعمل بالنقر على المجسم أو الخريطة، وتعطي نتائج مع طريقة الحساب.

## الأدوات
1. **مسافة بين نقطتين**
   - مسافة سطحية (Great-circle) على كرة نصف قطرها 1737.4 كم.
   - مسافة وترية (3D chord).
   - اتجاه (Bearing) من A إلى B.
   - فرق الارتفاع.
2. **مسار متعدد النقاط**
   - طول المسار، أعلى وأدنى ارتفاع، أقصى ميل، متوسط الميل.
   - مقطع ارتفاعي (Elevation profile).
3. **الميل والانحدار**
   - درجة، نسبة مئوية، واتجاه.
   - تصنيف: آمن / حذر / غير قابل للعبور (حسب عتبة يحددها المستخدم).
4. **خط الرؤية (Line of Sight)**
   - هل B مرئي من A مع تضاريس حقيقية؟
   - نقطة الحجب إن وجدت، وخلوص الرؤية بالأمتار.
   - تأثير انحناء القمر.
5. **قياس فوهة**
   - ثلاث نقاط على الحافة → قطر، عمق تقريبي، مركز.
6. **مسافات مرجعية**
   - المسافة إلى أقرب منطقة ظلام دائم (PSR) — إن توفرت الطبقة.
   - المسافة إلى نقطة تحت الأرض (sub-Earth) وموقعها.
   - بعد الشمس والأرض بالكيلومتر وAU، والقطر الزاوي.
7. **تصدير**
   - CSV للنقاط والنتائج.
   - صورة/PDF للتقرير.

## المعادلات
### المسافة السطحية
```
d = R * acos( sin φ1 sin φ2 + cos φ1 cos φ2 cos Δλ )
R = 1737.4 km
```
### المسافة الوترية
```
chord = 2R * asin( d / (2R) )
```
### الميل
```
slope_deg = atan( Δh / d )
slope_%   = 100 * Δh / d
```
### خط الرؤية مع الانحناء
لكل نقطة على المسار:
```
drop(di) = di * (D - di) / (2R)
effective_h = h_terrain - drop
visible إذا زاوية الهدف > أقصى زاوية تضاريس
```
### الاتجاه
```
bearing = atan2( sin Δλ cos φ2 , cos φ1 sin φ2 - sin φ1 cos φ2 cos Δλ )
```

## تجربة الاستخدام
1. المستخدم يختار أداة من شريط علوي.
2. ينقر على المجسم/الخريطة. تظهر النقاط كدبابيس مرقمة.
3. لوحة نتائج جانبية تتحدث فورا.
4. زر "إضافة للمقارنة" و"تصدير".

## قواعد الدقة
- الإحداثيات planetocentric، شرق موجب.
- الارتفاع من DEM بأقرب عينة (bilinear إن أمكن).
- نعرض دقة المصدر وعدم اليقين.
- لو النقطة خارج تغطية DEM عالية الدقة: نستخدم DEM العالمي ونحذر.
- المسافة السطحية كروية وليست جيوديسية على مجسم بيضاوي (القمر شبه كروي، الفرق ضئيل).

## حالات حدية
- نقطتان متطابقتان → صفر مع تنبيه.
- عبور القطب → المعادلة تتعامل معه، لكن نختبر حالات 180°.
- نقطة في منطقة بلا بيانات → `لا توجد بيانات` بدل صفر.
- مسار أطول من 500 كم → نحدد عدد العينات تلقائيا.
