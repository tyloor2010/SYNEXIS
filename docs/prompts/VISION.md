# SYNEXIS — Lunar Landing Site Navigator

A south-polar decision-screening experience for mission planners, energy/communications engineers, teachers/students and the public.

Core journey: select a location and landing date/duration; inspect Sun/Earth directions against authentic terrain; inspect visibility windows; compare up to four scenarios; supply power/battery inputs; export a source-traceable report.

Home includes an inspection Moon while scientific state belongs to Navigator. Terrain is integrated with Navigator. Measure handles source-based geographic measurements; Compare handles scenarios and mission requirements; Learn explains methods and limitations.

The engine computes. AI explains verified outputs only. Every displayed scientific number must have an authentic source or documented formula. Never promise mission certification, communications performance or a full thermal solution. Preserve the existing black-and-white space design, fonts, illustrations and animation. The website presentation remains removed.
